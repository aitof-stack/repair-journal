# Журнал заявок на ремонт оборудования

Веб-приложение для учета заявок на ремонт оборудования.

## Функции:
- Создание заявок на ремонт
- Управление пользователями с разными правами доступа
- Фильтрация и поиск заявок
- Экспорт данных в CSV
- Локальное хранение данных
- Адаптивный дизайн для мобильных устройств

## Установка:
1. Загрузите все файлы в одну папку
2. Откройте index.html в браузере
3. Используйте login.html для входа в систему

## Доступ:
- **Администраторы**: полный доступ
- **Авторы заявок**: только добавление заявок
- **Ремонтная служба**: только просмотр и завершение заявок
