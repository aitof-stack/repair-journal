# ТОИР — Заявки на ремонт оборудования

Веб-приложение для учёта заявок на ремонт оборудования с синхронизацией между устройствами.

## Функции

- Создание заявок с фото и QR-сканированием
- Статусы: Открыта → В ремонте → Ожидание запчастей → Выполнена
- Авторасчёт времени простоя
- Фильтрация и поиск заявок
- Экспорт в CSV и печать отчётов
- Синхронизация через Supabase (облачное хранилище данных)
- Локальное хранение в offline-режиме (localStorage)

## Разработка

### Локальный сервер

```powershell
powershell -ExecutionPolicy Bypass -File server.ps1
```

Открыть: http://localhost:8080

### Стек

- Чистый HTML/CSS/JS (без фреймворков)
- Supabase (REST API, PostgreSQL)
- Firebase (конфигурация подключения)
- GitHub Pages (хостинг)
- PWA (Service Worker, Manifest)
